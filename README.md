# Applied Machine Learning

This repository contains assignments and practical work completed for
**DSA 8401 – Applied Machine Learning** as part of the Master of Science in Data
Science and Analytics programme.

## Assignments

| Topic | Description |
|---|---|
| Data Pre-processing | Data preparation and exploratory preprocessing |
| Machine Learning Pipelines | Model development, evaluation and pipeline implementation |
| Neural Networks | Neural network experiments on MNIST, including a CNN benchmark |

## Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras
